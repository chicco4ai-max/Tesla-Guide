# Tesla Companion — Beginner to Pro

A mobile-first interactive guide for the refreshed Tesla Model Y in France. The first priority is a delivery-day inspection checklist, followed by ownership lessons, safe S3XY Commander / Buttons guidance, and research-based accessory recommendations.

## Project scope
- Premium, realistic Model Y photography, Pearl White exterior and Zen Grey interior
- Delivery checklist with specific checks, risk levels, and defect recording
- Local/private inspection progress; no personal VIN or delivery photos in this public repository
- Avoid unsafe modifications or bypasses of Tesla safety features

## Deployment
This repository is intended for free hosting on GitHub Pages from `main` branch and repository root (`/`).

## Status
Initial repository setup. The interactive website files will be added next.
